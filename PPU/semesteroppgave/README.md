# Semesteroppgave

Kopi av oppsettet fra arbeidskrav 1, med tittelen endret til semesteroppgave.

- `main.tex`: dokumentet du redigerer. Innholdet fra arbeidskrav 1 er beholdt som utgangspunkt og må erstattes med semesteroppgaven.
- `references.bib`: kopi av litteraturlisten fra arbeidskrav 1. Tilpass referansene til kildene du faktisk bruker.

Oppsettet bruker norsk språk, 12 punkts skrift, A4, marger på 2,5 cm og APA-referanser med Biber.

Bygg PDF fra denne mappen med `latexmk -pdf main.tex` dersom LaTeX er installert.
